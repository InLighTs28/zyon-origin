# Changelog

All notable changes to **ZyoN** (datapack) and **ZyoN - Resources** (resource pack).
Both packs share the same version number and must be used together.

Format: one section per version, newest first. `DP` = datapack, `RP` = resource pack.

---

## [1.0.0-beta.1] - 2026-11-18 · *Timers*

First public beta.

### Timer HUD
- **DP** New column of timers on the left of the screen: one line per running timer (icon, gauge, seconds left), blinking just before the end.
- **DP** Timers: core lock, Oath, Pulse (active + recharge from tier 5, with a ready flash and chime), charged hand (seal / shatter), incident (spike / intrusion), drift countdown, weakest seal (under 30 s), Essence kept.
- **DP** HUD power: new tooltip with the timer icons.
- **RP** Timer textures: icons, segmented gauge with glowing edge, pixel digits, animated ready ring; EN/FR texts.

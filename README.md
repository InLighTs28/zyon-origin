# ZyoN · The Pactbound

*Never heals alone. Never idles. To stop is to fade.*

An origin for **Origins** (Minecraft **1.21.1**, **NeoForge**): a network operator who lays circles of light beneath the living and routes them as one network: what hits one hits all.

Made of two packs that are always used together:

| Folder | Pack | Install in |
|---|---|---|
| [`datapack/`](datapack) | **ZyoN**: the origin, its seals, network and logic | `saves/<world>/datapacks/` |
| [`resourcepack/`](resourcepack) | **ZyoN - Resources**: HUD, seals, models, sounds, texts (EN/FR) | `resourcepacks/` |

**Requirements:** Origins 1.52 + Apoli 1.132 (NeoForge 1.21.1). No other mod needed.

> **Beta**: ZyoN is in public beta. Expect balance changes; report anything odd in the [issues](../../issues/new/choose).

## Download

Ready-to-use zips are attached to each [release](../../releases). Players should use the CurseForge or Modrinth pages; this repository tracks the project's history.

## Report a bug

Found a bug or have an idea? Open an [issue](../../issues/new/choose): a short form asks for the version, what happened and your logs.

## Versions

The current version is in [`VERSION`](VERSION); every change is listed in [`CHANGELOG.md`](CHANGELOG.md).
Each release is tagged `vX.Y.Z` (both packs share the same number). Beta builds are tagged `vX.Y.Z-beta.N`.

- `X.Y.Z+1`: fixes and small tweaks
- `X.Y+1.0`: new content
- `X+1.0.0`: changes that can break existing worlds
